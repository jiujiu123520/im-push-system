使用帮助
  1. 打开 APP 后进入「服务器配置」页面
  2. 填写 Push Key（从服务端获取）和服务器地址
  3. 点击「确认并连接」，看到顶部显示「在线」即连接成功 ✅

首次使用建议先点击「🧪 测试服务器连接」确认地址可用。

首页顶部展示连接状态卡片，包括：

  1. 当前连接状态（在线 / 离线）
  2. WebSocket 服务器完整地址
  3. 网络延迟实时数据
  4. 测试推送 / 重新连接两个快捷按钮

下方「最近消息」展示最新 3 条推送，「快捷操作」可以快速跳转。

消息列表支持以下操作：

  1. 🔍 搜索：按关键词搜索消息内容
  2. 🏷 筛选：全部 / 高优先 / 系统 / 未读 分类查看
  3. ✅ 一键已读：将所有未读标记为已读
  4. 🗑 清空：删除全部本地消息
  5. 单条操作：复制内容 / 标记已读 / 删除

未读消息左侧有蓝色竖线 + 红点提示 🔴

PushApp 内置三套精美主题，随时切换：

  1. ☀️ 浅色玻璃：默认，柔和的白色毛玻璃卡片
  2. 🌙 深色玻璃：护眼的暗夜毛玻璃风格
  3. 🚀 扁平渐变：深紫背景 + 暖橙主按钮，游戏感

进入「设置 → 通用 → 主题」即可点击切换，实时生效。本预览页顶部也提供了快捷切换控件。

「设置 → 网络」提供三个选项：

  • 仅 Wi-Fi：勾选后只在 Wi-Fi 环境连接，节省移动流量
  • 自动重连：断线后自动尝试重新连接（推荐开启）
  • 心跳间隔：15s / 30s / 60s，间隔越小越省电但流量更多

推荐配置：自动重连 ✅ + 心跳 30s（平衡省电与实时性）

要获得最佳推送体验，请确保系统权限全部开启：

  1. 📱 设备权限：必须开启才能接收推送
  2. 🔔 通知权限：关闭后将不会弹出通知
  3. 🔋 电池优化：建议关闭，防止被系统杀后台
  4. 🛡 自启动：开机自动启动 APP
  5. 🔒 后台弹窗：允许后台弹出通知详情

前往系统设置 → 应用管理 → PushApp 手动开启。
